# HIGH TECH PS - مركز صيانة أجهزة البلايستيشن

مرحباً بك في مشروع **HIGH TECH PS** الخاص بإدارة وتنظيم ملفات صيانة وتعديل أجهزة البلايستيشن.

## محتويات المشروع:
- `index.html`: الواجهة الرئيسية للمستخدم لعرض الخدمات والملفات المتاحة.
- `style.css`: ملف التصميم الخاص بالواجهة ليتناسب مع تجربة المستخدم (Dark Theme).
- `app.js`: الملف المسؤول عن إدارة تحميل الملفات (Payloads) عند الضغط على الأزرار.
- `cache.manifest`: ملف الكاش لتمكين العمل دون اتصال بالإنترنت (Offline Mode).

## طريقة الاستخدام:
1. قم بوضع ملفات الـ (Payloads) الخاصة بك داخل مجلد فرعي باسم `assets/`.
2. تأكد من مطابقة أسماء الملفات في مجلد `assets` مع المسارات المحددة في `cache.manifest`.
3. ارفع المشروع على خادم محلي (Localhost) أو استضفه على GitHub Pages لتبدأ في استخدامه من خلال متصفح جهاز البلايستيشن.
